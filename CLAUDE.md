
This is a project by Bill in collaboration with agents. 

- `docs/specification.md` is written by Bill. Agents use that document as a source of design ideals for the website. Agents do not make edits to that document except very concise edits where explicitly requested to by Bill. 
- `docs/specification.md` reflects Bill's vision it does not necessarily reflect the current state of the site. The spec can be ahead or behind of the actual state of work and agents will need to read the git log (and sometimes ask Bill) to undertand which parts are aspirational and which have gone stale. 
- The `README.md` is written by agents to reflect the current state of the project.
